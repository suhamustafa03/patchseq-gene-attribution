The research question

Among genes expressed in mouse interneurons, which track how they fire, and does that make biophysical sense? This project is building a pipeline to find candidate genes whose expression statistically tracks electrophysiological differences in mouse cortical interneurons, after controlling for subclass and donor, and to check whether those candidates are biophysically plausible against known ion-channel function. That analysis is distinct from prior cross-modal classification and mouse-to-human transfer-learning work — but it has not yet run on real transcriptomic data, for reasons explained below.

Run on real data

Quality control and donor-grouped cross-validation ran on real downloaded data. The resulting mouse–human electrophysiology comparison (450 mouse cells, 4 usable human cells) is preliminary and underpowered -- it does not establish a reliable species difference.

Tested on synthetic data

Candidate-gene attribution, stability selection, and the biophysical plausibility simulation are implemented and pass their tests, but have only ever been exercised on a synthetic, clearly-labeled demo fixture -- not on real biology.

Awaiting data permissions

Real mouse gene-attribution and biophysical plausibility checks are blocked: the relevant NeMO transcriptomic dataset currently has no license listed. Research continues on verified, permitted data in the meantime.

What this project has shown

  • A tested, reproducible pipeline for gene-attribution, stability selection, and plausibility screening.
  • A working real-data QC and donor-grouped cross-validation workflow, run on real downloaded data.
  • A clear, honest map of exactly what's blocked and why.

What this project has not shown

  • No real candidate genes have been identified.
  • No reliable mouse–human electrophysiological difference (n=4 human cells).
  • No causal claim, and no completed gene-attribution study.

How the method works

Why measure gene expression and electrophysiology in the same cell?

Patch-seq records a neuron's electrical activity with a patch-clamp electrode, then extracts and sequences its RNA through the same pipette. Because both measurements come from one cell, any statistical link between a gene and an electrical feature is at least a same-cell association -- not a guess from averaging across different cells.

Why "candidate," not "cause"?

A gene's expression can track an electrical feature for reasons that have nothing to do with it causing that feature -- shared developmental timing, cell subclass, or donor-level variation can all produce the same statistical pattern. Stability selection and donor-grouped cross-validation reduce, but do not eliminate, this risk.

What does the plausibility loop actually check?

For a handful of genes with a well-documented ion-channel role (e.g. a potassium or sodium channel gene), a small conductance-based neuron model is perturbed in the direction the expression difference implies, and the resulting shift in firing behavior is compared -- in direction only -- against what was measured. Agreement is weak supporting evidence, not confirmation.

Scope at a glance

  • Mouse arm (attribution): Gouwens et al. 2020 Patch-seq cohort, n=4,270 interneurons, ephys + transcriptome + partial morphology, linked per cell.
  • Human arm (ephys-only comparison): DANDI:000636, 109 subjects / 616 cells, electrophysiology only -- no transcriptome, no confirmed subclass labels.
  • Not in scope yet: any cross-species gene attribution, which would require a linked human transcriptome (see Data & Licensing for the Lee & Dalley 2023 upgrade path, not currently used).
Where things actually stand (2026-11-23). A real, non-synthetic data pull and partial pipeline run has been completed, but it is a preliminary feasibility check, not a scientific result:
  • Mouse gene-attribution arm: not run on real data. No real gene-expression (transcriptome) data was obtained, because the NeMO mouse-transcriptome collection currently has no license listed and was therefore not downloaded, per this project's own stop condition. No mouse genes have been identified as candidates from real data at any point.
  • Human ephys-only cross-species comparison arm: ran on real data, but on only 4 usable cells. Of 20 downloaded DANDI:000636 NWB files, only 4 yielded ephys features extractable with the pipeline's current feature-extraction settings (the other 16 failed because their stimulus-naming convention isn't recognized by the extractor's default configuration -- an unresolved pipeline limitation, not a statement that those recordings are unusable by any method). With n=4, the resulting mouse-vs-human descriptive numbers are preliminary only and do not demonstrate a reliable species difference.
  • The real mouse cells came from the Allen Brain Map REST API, Cre-line-filtered as a subclass proxy -- not independently verified as the exact published Gouwens et al. 2020 cohort.
A separate, clearly synthetic demo fixture (demo_fixture/) was also run end-to-end to validate that the pipeline code itself is correct. Its numbers are 100% synthetic and must never be read as biological findings -- they are kept visually and textually separate from the real-data numbers throughout this site. See Results for both, and Reproducibility for exact commands.

What this project does not claim

  • No causal gene → channel → excitability proof from observational data.
  • No cross-species gene attribution.
  • No simulation result is validation -- conductance-based models are a plausibility/sensitivity check only.
  • Null, inconclusive, or unstable results are reported, not hidden.
