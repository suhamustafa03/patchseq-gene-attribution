Reproducibility

The commands below reproduce the synthetic demo fixture run, with no download required.

cd project/
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt   # core deps: numpy, pandas, scikit-learn, pytest
python3 demo_fixture/generate_demo_fixture.py
pytest -q
python3 -m patchseq_genes.run_pipeline --input demo_fixture --output results/demo

Optional: run the Brian2 biophysical plausibility screen too (pip install brian2 first):

python3 -m patchseq_genes.run_pipeline --input demo_fixture --output results/demo --run-simulation

Real-data run (2026-11-23): exploratory feasibility check, already executed

A real, non-synthetic data pull and partial pipeline run has already been executed -- this is not a to-do. Full provenance (source URLs, dataset versions, download date, file counts, checksums) is recorded in docs/DATA_MANIFEST.md; what ran and what was blocked is summarized in docs/PROGRESS_REPORT.md; the code path used is src/patchseq_genes/real_data_adapter.py, which calls the same unmodified qc.py / features.py / confounders.py / cv.py functions as the demo run; outputs are in results/real/ (summary.json, cross_species_ephys_table.csv, cross_species_confounders.csv), kept separate from results/demo/.

What this run is -- and is not. It is an exploratory feasibility check, not a completed gene-attribution study:
  • Real human ephys features were extracted from only 4 of 20 downloaded DANDI:000636 NWB files (the other 16 failed on an unrecognized stimulus-naming convention -- an unresolved pipeline limitation, not a claim those recordings are unusable). With n=4, the result is preliminary and does not demonstrate a reliable species difference.
  • The real mouse cells are a Cre-line-filtered proxy pulled from the Allen Brain Map REST API, not a verified match to the published Gouwens et al. 2020 Patch-seq cohort.
  • The real mouse gene-attribution analysis was not run: the NeMO mouse-transcriptome collection (dat-m2kd56v) currently shows no license listed, so it was not downloaded, per this project's own license stop-condition. No mouse genes have been identified as candidates from real data.
  • Synthetic demo results (results/demo/) remain entirely separate from these real-data results and must never be read as biological findings.

This real-data run is not independently re-runnable from a single command in this repository (it required interactively enumerating and selecting a subset of DANDI:000636 assets and querying the Allen Brain Map REST API as a documented allensdk substitute); see docs/DATA_MANIFEST.md for the exact commands actually used.
