Limitations

  • Small human N, even with transcriptome. DANDI:000636 has 616 cells from 109 subjects; even if a linked human transcriptome existed, this would be a modest sample for gene-level inference, with substantial multiple-donor clustering.
  • Donor confounding. Multiple cells per donor share technical and biological variation; donor-grouped CV avoids leakage but does not remove the underlying confound -- a found association could still partly reflect donor-level rather than gene-level variation.
  • Feature mismatch across species. Ephys acquisition protocols, electrode/solution conditions, and subclass taxonomies differ between the Allen Institute mouse pipeline and the DANDI:000636 human dataset; the ephys-only cross-species comparison arm should be read as a coarse phenotypic comparison, not a precisely matched one.
  • No causal claims. All statistical attribution results are associations after confounder control, not causal estimates; the simulation step is a plausibility screen, not an independent causal test.
  • Open licensing items. The Lee & Dalley 2023 dataset's exact accession and data-specific license are not yet confirmed, which is why it is not used. The NeMO per-dataset license tag for the Gouwens 2020 bundle should be re-verified at download time, since license metadata can be set at the sub-collection level.
  • Demo results remain synthetic. The demo/synthetic section of the Results page is from a fixture used only to validate the pipeline code; it says nothing about biology.
  • Real-data human N is 4 cells -- preliminary only. Of 20 downloaded DANDI:000636 files, only 4 yielded ephys features extractable with ipfx's default stimulus detection; the other 16 failed because their stimulus-naming convention isn't recognized by the extractor's default configuration. This is an unresolved pipeline limitation, not evidence that those recordings are unusable by any possible extraction method. The real-data cross-species comparison numbers are descriptive only, not statistically powered, and do not demonstrate a reliable species difference.
  • Real mouse cohort is a Cre-line proxy, not a verified Gouwens-2020 subset match. The 522 real mouse cells came from the Allen Cell Types Database's general query interface, filtered by Cre-line name as a GABAergic-subclass proxy; it was not confirmed in the time available that every cell is specifically part of the published Gouwens et al. 2020 Patch-seq release.
  • Mouse gene-attribution arm is blocked, not run. The real NeMO mouse-transcriptome bundle (dat-m2kd56v) now shows no license listed on re-check (2026-11-23), so it was not downloaded; no real gene-expression input exists for this project, and the attribution/stability-selection code has only ever run on the synthetic demo fixture.
