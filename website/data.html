An atmospheric, slowly animated scene: a mouse silhouette on the left and a human silhouette on the right, each with a softly glowing brain region, connected by faint neural-pathway lines. Small points of light drift along these lines toward the center, where they resolve into a simple electrical waveform. This is a conceptual illustration of the project's guiding question -- it does not depict any measured gene, signal, or result.

From genes to firing

An exploratory feasibility study of interneurons, gene expression, and electrical activity — across mouse and human.

Data & Licensing

Only two datasets are in scope for this project. No raw data is downloaded or committed as part of building this repository; see data/README.md for full provenance notes.

DatasetSpecies / contentScaleLicenseLink
Gouwens et al. 2020 Patch-seq cohort Mouse; ephys + transcriptome + partial morphology, linked per cell n=4,270 interneurons CC-BY-4.0 (parent NeMO collection) NeMO dat-m2kd56v
DANDI:000636 Human; electrophysiology only -- no transcriptome, no confirmed subclass labels 109 subjects / 616 cells CC-BY-4.0 (confirmed via raw DANDI API metadata) dandiarchive.org/dandiset/000636
No cross-species gene attribution. This project does not use any human transcriptomic data. The human arm is restricted to an ephys-only phenotypic comparison across species; it is never merged with mouse gene expression.

Real-data pull (2026-11-23)

A real (non-synthetic) data pull was performed; full provenance is in docs/DATA_MANIFEST.md. Summary:

DatasetWhat was obtainedLicense re-check
DANDI:000636 (human ephys) Real subset: 20 of 706 NWB files (~597 MB of the 24.5 GB dandiset), 20 distinct subjects, version 0.241120.0510 CC-BY-4.0, re-confirmed 2026-11-23
Allen Cell Types Database (mouse ephys + metadata, Gouwens-overlapping Cre lines) Real: 522 cells, 263 donors, via the Allen Brain Map REST API (used in place of allensdk, which does not install on Python 3.13 -- see manifest) NeMO dat-7uhwm74 (ephys/morphology): CC BY 4.0, re-confirmed
NeMO dat-m2kd56v (mouse transcriptome) NOT downloaded. Blocked. Re-check 2026-11-23: page now shows "No license listed" -- a change from the prior CC-BY-4.0 status, so it was not used, per this project's own license stop-condition.
Consequence: because the mouse transcriptome source is currently blocked on licensing, the mouse gene-attribution arm could not be run on real data. The human ephys-only cross-species comparison arm (which needs no transcriptome) was run on this real data -- see Results.

Possible future upgrade (not in use)

Lee, Dalley, et al. 2023 (Science 382:eadf6484, n=778 human Patch-seq neurons with linked transcriptome) is the natural path to a true cross-species gene-attribution arm. Its exact data accession and data-specific license have not been confirmed as of this writing. It is noted here only as a possible future upgrade -- it is not used anywhere in this codebase or on this site.
