Methods

Summarized from docs/stage2_research_design.md; see that file for the full design rationale.

Real-data run (2026-11-23): on real data, only steps 1-4 below ran (QC, ephys-only feature construction, confounder matrix, donor-grouped CV leakage check), via the new src/patchseq_genes/real_data_adapter.py, which calls the same unmodified qc.py / features.py / confounders.py / cv.py functions used on the demo fixture. Steps 5-6 (baseline attribution models, stability selection) require gene expression input, which was not available for real data (no accessible, properly licensed, cell-linked mouse transcriptome -- see Data & Licensing) and so did not run on real data. Step 7 (simulation) was not run on real data either. See docs/DATA_MANIFEST.md and results/real/summary.json.

1. QC and schema validation

Required columns, types, and uniqueness of cell_id are enforced before any modeling. Rows missing a key ephys feature are dropped, rather than silently propagating NaNs into a regression.

2. Feature construction (two separate arms)

Attribution arm: restricted to mouse cells with has_transcriptome=True; uses gene expression + ephys.

Ephys-only cross-species comparison arm: uses all cells, both species, ephys features only -- expression data never enters this arm, since the human dataset has no transcriptome.

3. Confounder control

Subclass is one-hot encoded and included as a covariate. Donor identity is kept as a grouping key for cross-validation, never as a model feature, so a model cannot simply memorize per-donor baselines.

4. Donor-grouped cross-validation

Splits are grouped by donor_id (via scikit-learn's GroupKFold / GroupShuffleSplit), not by cell_id. Multiple cells from the same donor share donor-level technical and biological variation; a cell-level split would leak donor identity between train and test and overstate predictability.

5. Baseline attribution models

Ridge and lasso regression map gene expression (plus subclass covariates) to a target ephys feature. A reduced-rank baseline (truncated-SVD of the expression matrix, then linear regression on the top components) is included as a simpler alternative to a dedicated reduced-rank-regression library.

6. Stability selection with a negative control

Repeated subsampling + lasso estimates a per-gene selection frequency. A negative control repeats the identical procedure after permuting the target label, to estimate a null selection-frequency distribution. A gene is only called "stable" if its real frequency clears the null frequency by a pre-specified margin. A pre-specified minimum count of stable genes (STABLE_GENE_MIN_COUNT in run_pipeline.py) is used to call a result null/inconclusive -- chosen before looking at any results, not tuned afterward.

7. Simulation as a plausibility check, not validation

A minimal single-compartment conductance-based neuron model (Brian2) perturbs the conductance mapped to a candidate gene (via a small, explicitly "illustrative/simplified" gene→channel lookup table) and reports the direction of the resulting firing-rate / AP-width shift. This checks whether a statistical association is at least qualitatively consistent with known channel biophysics -- it does not validate or prove the association.
