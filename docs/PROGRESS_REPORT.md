# Progress Report

## 1. What has been built

The full pipeline described in `docs/stage2_research_design.md` is
implemented in `src/patchseq_genes/` (QC, feature construction for both
analysis arms, confounder control, donor-grouped CV, baseline attribution
models, stability selection with a negative control, and a Brian2-based
biophysical plausibility screen), with a pytest suite in `tests/` and a
static website in `website/`.

## 2. What has actually been run

- `demo_fixture/` -- a small, 100% synthetic fixture generated by
  `demo_fixture/generate_demo_fixture.py` -- has been run through the
  full pipeline end to end. See `results/demo/summary.json` for the
  actual output of that run, and `website/results.html` for how it is
  presented (clearly labeled as a pipeline-validation run on synthetic
  data, not a scientific result).
- **(2026-11-23) A real-data run was executed.** See
  `docs/DATA_MANIFEST.md` for full provenance and
  `results/real/summary.json` for output. Summary: a real 20-file / 597 MB
  subset of DANDI:000636 (human Patch-seq ephys, CC-BY-4.0) was downloaded
  and real ephys features extracted with `ipfx`; 522 real mouse
  interneuron cells (ephys + Cre-line/donor metadata) were pulled from the
  Allen Cell Types Database REST API (used as a documented fallback for
  `allensdk`, which still does not install on this Python 3.13
  environment). The **human ephys-only cross-species comparison arm ran
  successfully on this real data** (454 cells post-QC: 450 mouse + 4
  human, donor-grouped CV leakage check passed on real donor IDs). The
  **mouse gene-attribution arm remains blocked** -- see section 3.

## 3. What has NOT been run / remains blocked

- **Mouse gene-attribution arm (real data): BLOCKED.** No real, properly
  licensed, cell-linked mouse transcriptome was obtained. On re-check
  (2026-11-23) NeMO `dat-m2kd56v` (the Gouwens 2020 transcriptome bundle)
  now shows **"No license listed"** -- a regression from the CC-BY-4.0
  status recorded in the prior audit -- so per this project's own stop
  condition it was not downloaded or used, on top of the still-unresolved
  cell-linkage question noted below. `src/patchseq_genes/attribution.py`
  and `src/patchseq_genes/stability.py` were therefore never invoked on
  real data; only on `demo_fixture/`.
- Full-scale downloads were intentionally not performed: only 20 of 706
  DANDI:000636 NWB files and 522 of ~1920 queryable Allen mouse cells were
  pulled, as an honestly-labeled subset given time constraints (see
  `docs/DATA_MANIFEST.md`).
- Of the 20 downloaded human NWB files, only 4 yielded ephys features
  `ipfx` could extract with default settings (16 failed because their
  long-square stimulus naming isn't recognized by ipfx's default
  ontology) -- a real extraction limitation, reported rather than hidden.
- **Lee, Dalley, et al. 2023** (*Science* 382:eadf6484) accession search
  concluded (2026-11-23, prior audit): DANDI 000636 is confirmed as the
  paper's human ephys data, but it is ephys-only; no confirmed
  linked-transcriptome accession for this study was found. Scope remains
  mouse-only attribution (blocked) + human-ephys-only comparison (run on
  real data).

Every number describing pipeline-validation "results" from
`demo_fixture/` is still 100% synthetic, unchanged, and clearly separated
from the real-data numbers in `results/real/summary.json`.

## 4. Open items

- **Lee, Dalley, et al. 2023** (*Science* 382:eadf6484) accession search
  concluded (2026-11-23): DANDI 000636 is confirmed as the paper's human
  ephys data (license `spdx:CC-BY-4.0`, confirmed via raw API at
  `/api/dandisets/000636/versions/0.241120.0510/`), but it is ephys-only.
  No confirmed accession containing linked ephys+transcriptome for this
  study was found. The closest candidate transcriptomic resource,
  NeMO `col-e3gka8n` ("Human neocortical patch-seq transcriptomics",
  https://assets.nemoarchive.org/collection/nemo:col-e3gka8n, stated
  terms: public data under CC BY 4.0, controlled-access data under a
  separate data-use certification per biccn.org/terms-of-use), could
  NOT be confirmed as specifically this paper's release vs. a broader
  ongoing lab collection, and carries no sample counts or per-cell
  linkage information on its own page. **Conclusion: the cross-species
  gene-attribution upgrade path remains blocked; the project stays on
  the mouse-only attribution + human-ephys-only comparison scope.**
- The NeMO per-dataset license tag for the Gouwens 2020 bundle should be
  re-verified at actual download time (license metadata can be set at
  the sub-collection level, below the parent CC-BY-4.0 tag).
- `allensdk` failed to install in the environment used to build this
  repository (incompatible with the installed Python/`setuptools`
  toolchain); `dandi` and `brian2` installed and ran successfully. This
  does not block anything in this repository, since neither download
  script nor the simulation step is run as part of building it, but a
  user running the real download on their own machine should expect to
  need a compatible Python version for `allensdk`.
